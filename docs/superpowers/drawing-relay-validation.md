## 실제 모바일 화면 확인

2026-10-21, Chromium 375×812에서 기존 폭탄 돌리기, 홈, 새 게임 소개·대기실·문장·그림판·결과를 열어 확인했다. 기존 PartialSansKR-Regular 글꼴, MainButton, chocolate 색상, GameMenu, 공통 방 UI를 재사용한다.

실제 화면에서 발견한 제목 줄바꿈, 6색 버튼의 두 줄 배치, 시간 막대의 기본 초록색을 수정했다. 제목은 같은 글꼴에서 모바일 폭에 맞춰 크기를 줄였고, 그림판 내부 여백을 줄여 44px 버튼 여섯 개를 한 줄로 유지했다. 시간 막대는 chocolate 토큰을 사용한다. 375px 가로 넘침과 소개 화면 pageerror는 없다.

- ESLint는 기존 설정에서 직접 import하는 @eslint/js가 현재 pnpm 설치의 최상위에 없어 실행하지 못했다. lint 통과를 주장하지 않는다.

## 실행 환경

제한된 기본 실행 환경에서는 네트워크 및 포트가 차단됐다. 허용된 네트워크 권한으로 패키지와 기존 원본 에셋을 확보했다. 개발 서버는 HMR 연결 오류로 클릭 동작이 초기화되지 않아, 별도 정식 빌드 서버로 전환해 위 테스트를 수행했다. 원본 에셋은 프리뷰 복원에만 사용하며 변경 패치에 중복 추가하지 않는다. 설치로 발생한 lockfile 변경은 복원했다.

운영 반영 시 Worker를 먼저 배포한 후 웹을 반영해야 한다. 현재 프리뷰는 임시 로컬 환경이며 휴대폰에서 바로 열 수 있는 공개 주소는 아니다. 세션 저장이 차단된 환경에서는 탭 메모리로 유지하므로 새로고침 후 복원은 보장하지 않는다. 서버는 마감 전에 도착한 마지막 초안으로 시간 초과 제출을 확정한다.

## 화면 테두리 피드백 반영

사용자 요청에 따라 낙서 이어달리기·폭탄 돌리기·팀 나누기의 외곽 카드 및 중첩 섹션 테두리와 가로 여백을 제거했다. 사다리 설정/게임판과 초성 퀴즈 문제 영역의 장식용 테두리도 제거했다. 입력·선택 컨트롤과 그림판 경계는 유지한다. 기존 커피내기·룰렛은 변경하지 않았다.

캡처용 네 명의 닉네임은 민지·현우·서연·지훈으로 통일하고 HTML 실행 방지 확인용 문자열을 화면 캡처에서 제외했다. 테스트 문자열이 그대로 보인 것은 사용자 입력을 텍스트로 렌더링한 결과이며 스크립트 실행을 의미하지 않는다.

정식 webpack 빌드 통과, 기존 Vitest 16개와 신규 Node 18개 통과, 실제 Worker 연결 4인 브라우저 테스트 재실행 통과(22.2초). 360px와 375px에서 폭탄 돌리기·팀 나누기·사다리·초성 퀴즈의 레이아웃 섹션 border/padding이 0px이고 가로 넘침이 없음을 확인했다. 낙서 대기실·그림판도 실제 캡처로 재확인했다. 운영 서버 배포는 별도다.

main 반영 전 추가 검증: 실제 Worker 테스트 3개 파일/16개 테스트 통과. 검토용 캡처 이미지와 미리보기 문서는 사용자 요청에 따라 제거했다.
